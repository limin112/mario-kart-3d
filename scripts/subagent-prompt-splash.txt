【任务】新建 game/splash.js —— 马里奥赛车式开屏 logo 大字动画，纯 DOM+CSS，零 import、
零外部资源、零音频、零 console 输出。主 agent 会在 main.js 里这样调用（契约必须严格一致）：

  import { startSplash } from './splash.js';
  startSplash(onDone);   // onDone: () => void

startSplash(onDone) 契约：
- 调用即向 document.body 注入自己的 <style id="splash-style"> 和全屏遮罩
  <div id="splashOverlay">（position:fixed; inset:0; z-index:9000; flex 居中；
  背景深色径向渐变 alpha≈0.92，隐约透出后面的 3D 舞台）。
- 大字 logo「SUPER PI KART」（红→橙渐变文字、白色描边、微倾斜，马力欧赛车味）+
  副标题「★ 3D GRAND PRIX ★」。字体用系统字体栈即可。
- 时间线（毫秒，用 rAF 或 setTimeout 都行，但必须基于时间戳、掉帧时不卡死）：
  0     遮罩淡入 200ms
  150   logo 砸入：scale 3.2→1，easeOutBack 回弹，450ms
  550   副标题从下方滑入淡入 400ms
  700   logo 上扫过一道高光（shine sweep，600ms）
  1400  底部「按任意键 / 点击开始」提示开始闪烁
  2300  自动退场：内容 scale 1→1.15 + 整体淡出 300ms，然后移除注入的 DOM 节点、
        移除所有事件监听、调用 onDone()
- 跳过：t≥500ms 后的 window keydown/click/touchstart 任一 → 立即进入退场（250ms）
  → 同样清理并 onDone()。不要 preventDefault（别影响游戏键盘状态）。
- onDone 在所有路径上必须且只能被调用一次（内部 guard）。重复调用 startSplash
  第二次直接忽略。document 上事件监听退场后必须全部移除，不留残留。
- 文件头写注释说明契约。代码风格参考 game/touch.js（也是自注入 DOM 的独立模块）。
