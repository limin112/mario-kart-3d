# 你的子任务（P14 新地图·第一步：赛道布局数据）

新建一个文件 game/trackdefs.js —— 纯数据模块，为 P14 新赛道提供样条控制点布局。
主 agent 正在并行改 track.js/themes.js/main.js，你【只许新建这一个文件】。

## 文件契约（必须严格遵守，主 agent 按此对接）

game/trackdefs.js 内容要求：
- 纯数据 ES module：零 import、零依赖、零副作用（不碰 document/window/THREE）。
- 只导出一个常量：export const TRACK_LAYOUTS = { classic: {...}, dune: {...}, glacier: {...} };
- 每个布局对象字段：
  - name: 中文名（如 '经典草原环线' / '沙漠环丘赛道' / '雪山冰原赛道'）
  - theme: 建议主题名，字符串，取值 'classic' / 'desert' / 'snow'（对应主 agent 的 themes.js）
  - roadWidth: 路面半宽，数字（classic 用 12，新图可 10~13）
  - controlPoints: [[x,z],[x,z],...] 纯数字数组的数组（不要 THREE.Vector3，不要 y 分量）

## 布局设计要求

- classic：必须与现有 game/track.js 里 TRACK_CONFIG.controlPoints 的 9 个点完全一致（把它们转成 [x,z] 数组抄过来）。
- dune（沙漠）：10~13 个点，要有 1 条长直道（连续两段各 >45m 且方向近似）和至少 1 个发夹弯（连续三点转向 >120°）。
- glacier（雪山）：10~13 个点，要有 S 组合弯（连续两个反向弯）和 1 个发夹弯。
- 所有布局：坐标范围 |x|,|z| ≤ 90；相邻控制点间距 15~60m；控制点依次连线构成的多边形必须是简单多边形（不自交）——闭环赛道不自交是硬要求。
- 曲线是 CatmullRom 闭环（centripetal, tension 0.5），点别太密也别共线太多，保证弯形明显。
