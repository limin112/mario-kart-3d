# Mario Kart 3D

一个在浏览器中可玩的 3D 卡丁车竞速游戏，风格对标马里奥赛车。

## 🎮 快速开始

### 方式一：双击启动（推荐）
- **Linux/macOS**: 双击 `launch.sh`（或在终端运行 `./launch.sh`）
- **Windows**: 双击 `launch.bat`

脚本会自动：
1. 启动本地 HTTP 服务器（端口 8901）
2. 在默认浏览器中打开游戏
3. 关闭终端窗口即可停止服务器并退出

### 方式二：手动启动
```bash
cd game
python3 -m http.server 8901
```
然后在浏览器访问 `http://127.0.0.1:8901/`

> **手机也能玩**: 服务器启动后，手机与电脑连同一 Wi-Fi，用手机浏览器访问 `http://<电脑局域网IP>:8901/` 即可出现触屏虚拟按键（详见下方「📱 移动端触屏」）。

> **注意**: 由于使用 ES Modules 和 importmap，必须通过 HTTP 服务器访问，不能直接双击 `game/index.html` 打开（file:// 协议会被 CORS 策略拦截）。

## 🕹️ 游戏操作

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 油门 / 前进 |
| `S` / `↓` | 刹车 / 倒车 |
| `A` / `←` | 左转 |
| `D` / `→` | 右转 |
| `Space` | 使用道具 |
| `M` | 静音 / 取消静音（右上角状态提示） |
| `R` | 重新开始（比赛结束后） |
| 任意键 / 点击 | 跳过展示模式进入比赛 |

## 📱 移动端触屏

在智能手机或平板的浏览器中打开游戏地址，会自动出现半透明虚拟按键（桌面端不显示，键盘操作不受影响）：

| 位置 | 按键 | 功能 |
|------|------|------|
| 左下 | `◀` / `▶` | 左转 / 右转 |
| 右下 | `加速` | 油门 / 加速 |
| 右下 | `刹车` | 刹车 / 倒车 |
| 右下 | `道具` | 使用道具 |
| 右上 | `↺` | 重新开始 |

- **建议横屏游玩**，视野更好。
- **推荐手机访问方式**: 手机与电脑连同一 Wi-Fi 时，直接访问 `http://<电脑局域网IP>:8901/`（在 `launch.sh` 启动的 `http://127.0.0.1:8901/` 基础上，把地址换成电脑的局域网 IP，可用 `hostname -I` / `ipconfig` 查看）。

## 🏁 游戏流程

1. **车辆展示模式** (约 4 秒) — 卡丁车爆炸拆解展示，镜头环绕，按任意键或点击可跳过
2. **3-2-1-GO 倒计时** — 准备起跑
3. **3 圈竞速比赛** — 与 3 台 AI 对手竞速，收集道具，利用加速带
4. **结算界面** — 显示每圈用时、总时间、最终名次

## 🎯 游戏特性

- **街机式物理**: 加速、摩擦、转向随速度衰减，易上手有深度
- **完整赛道**: CatmullRom 样条闭环赛道，路面、路肩、护栏、起点拱门、树木、看台、观众、路灯、路标、轮胎堆
- **3 圈制 + 检查点防切弯**: 8 个检查点确保公平竞速
- **3 台 AI 对手**: 个性化速度差异、前瞻转向、弯道减速、橡皮筋机制（落后加速/领先减速）
- **道具系统**: 8 个 `?` 道具箱（每圈刷新），随机开出蘑菇加速（3 秒 1.8x）或香蕉皮（扔出身后，打滑 1.5 秒）
- **加速带**: 赛道上 3 条蓝色加速带
- **粒子特效**: 轮胎烟雾、加速带粒子、道具拾取爆发、打滑星星
- **精美 UI**: 玻璃态 HUD、等宽数字字体、SVG 道具图标、动画倒计时/结算
- **动态环境**: 天空盒渐变、飘动云朵、呼吸式路灯、晃动/挥手观众
- **车辆展示模式**: 学习四驱兄弟宣传片风格的爆炸拆解展示

## 🛠️ 技术栈

- **Three.js r160** (本地 vendor，无 CDN 依赖)
- 纯 HTML + JavaScript (ES Modules)，**无构建工具**
- WebAudio 程序化音效：引擎音随速度变调、倒计时/GO 提示音、道具拾取/加速/打滑/加速带 whoosh 音效（纯合成，无音频文件；首次按键/点击后启用，`M` 键可随时静音）
- 程序化几何体/纹理生成，无外部资产文件
